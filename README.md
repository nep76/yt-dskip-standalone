# YouTube DSkip - Standalone

YouTubeの広告を自動スキップするChrome拡張です。
広告そのものの回避はせずスキップボタンを代理でクリックします。

**Chrome Debugger API**を利用してユーザークリックを模倣することで広告をスキップします。広告の通信やYouTube内部のAPIに介入しません。

また、使用中はデバッガがアタッチされていることを示す通知が表示される場合があります。

> [!CAUTION]
> ### Chrome Debugger API
> このAPIは**拡張機能からページ上の操作・通信の監視が可能な強力な機能**です。
本拡張ではクリック操作のためにのみ使用していますが、技術的にはより広い範囲でブラウザの操作を行うことが可能なものです。
> 
> 通常のJavaScriptからのクリックはYouTube側に検知されますが、デバッガを使ったクリックではユーザー操作に近い入力して処理されるため検知されにくいと考えられます。
> 
> ソースコードを確認し、信用して頂ける場合のみ本拡張機能をご利用ください。
>
> ### 使用箇所
> 
> yt-dskip-standalone-worker.jsのonMessageイベントリスナーでsw.adskip.node.foundメッセージを処理（182行目付近）する中で使用しています。
> 
> 具体的にはデバッガをアタッチ→クリック→デバッガをデタッチと操作しています。
> 
> 他の部分では一切アタッチしていません。

## その他の機能
* プレイリスト再生中にプレイリストから抜けて単独の再生ページに移動
* 再生中の動画のサムネイルの確認

## 備考
### 手動スキップ
ホットキーでスキップボタンを押すには拡張機能の設定から「スキップを手動実行する」のホットキーを設定してください。
範囲をグローバルにするとブラウザが前面になくても実行できます。

### アイドル時
今のところ、180分間端末の操作が行われなかった場合はサスペンドモードに切り替わり自動スキップが停止します。端末操作を行うと自動で復帰します。
