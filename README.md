# YouTube DSkip - Standalone

YouTubeの広告を自動スキップするChrome拡張です。
広告そのものの回避はせずスキップボタンを代理でクリックします。

Chrome Debugger APIを利用してユーザークリックを模倣することで広告をスキップします。広告の通信やYouTube内部のAPIに介入しません。

また、使用中はデバッガがアタッチされていることを示す通知が表示される場合があります。

### Chrome Debugger API
このAPIは拡張機能からページ上の操作・通信の監視が可能な強力な機能です。
本拡張ではクリック操作のためにのみ使用していますが、技術的にはより広い範囲でブラウザの操作を行うことが可能なものです。

通常のJavaScriptからのクリックはYouTube側に無視されますが、デバッガを使ったクリックではユーザー操作に近い入力して処理されるため使用しています。

ソースコードを確認し、動作を信用できる場合のみ使用してください。

### 使用箇所

yt-dskip-standalone-worker.jsの142行目付近からのSKIPNODE_FOUNDメッセージの処理の中で使用しています。

具体的にはデバッガをアタッチ→クリック→デバッガをデタッチと操作しています。

他の部分では一切アタッチしていません。
